# 🖊️ 中文寫作訓練器

中文寫作訓練 Streamlit app — 小六考試程度。材料 100% 嚟自課堂寫作記錄（作文內容會喺考試出現！）。

## 三個模式

### 📖 技巧操練（8 個 Topic，49 題 + 常設綜合題）

作文相關寫作元素題庫：

1. 描寫方法（動作・外貌・語言・心理）
2. 修辭手法（比喻・排比・設問・反問・擬人）
3. 襯托手法（正襯・反襯）
4. 層遞手法（由淺入深）
5. 標點符號（對白・感嘆・頓號）
6. 古詩意象與手法（借景抒情・托物言志）
7. 記敘文要素（最後的姿態）
8. 同義詞與錯別字（寫作基本功）

可揀 Topic（多選），每題附「✏️ 記得用」提醒。

### 🧰 寫作工具箱（8 大元素速查）

寫作前睇一次：描寫方法／修辭／襯托／層遞／首尾呼應／標點／錯別字／記敘文六要素，附常見錯誤。

### ✍️ 作文任務（AI 批改）

揀題目寫短文 → AI 按中文作文評分準則批改：
- 元素檢查（✅/❌）
- 錯別字/標點/病句修正（原句 → 改正）
- 內容與結構評語
- 升級示範（用上教過嘅寫作元素）
- 分數（內容 30%／結構 25%／描寫修辭 25%／標點字詞 20%）

**作文題目：**
1. 命題記敘文：難忘的一件事
2. 睇圖作文
3. 寫人：我最敬佩的人
